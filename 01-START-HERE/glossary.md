# قاموس المصطلحات

مرتبة أبجدياً بالاختصار الإنجليزي (لأنك ستتعامل معها بالإنجليزية في المواقع الرسمية). التحقق من التعريفات: 2026-11-22.

| الاختصار | الاسم الكامل | المعنى العملي |
|---|---|---|
| IRCC | Immigration, Refugees and Citizenship Canada | الوزارة الفيدرالية المسؤولة عن الهجرة والتأشيرات والتصاريح والجنسية |
| ESDC | Employment and Social Development Canada | وزارة التوظيف؛ تصدر LMIA عبر Service Canada |
| CBSA | Canada Border Services Agency | وكالة الحدود؛ قرار الدخول النهائي عند الوصول |
| IRB | Immigration and Refugee Board | المجلس المستقل الفاصل في اللجوء والاستئناف |
| MIFI | Ministère de l'Immigration, de la Francisation et de l'Intégration | وزارة الهجرة في كيبيك |
| PR | Permanent Residence | الإقامة الدائمة |
| TR | Temporary Residence | الإقامة المؤقتة (زيارة/دراسة/عمل) |
| TRV | Temporary Resident Visa | تأشيرة الزيارة الملصقة في الجواز |
| eTA | Electronic Travel Authorization | تصريح سفر إلكتروني للدول المعفاة من التأشيرة (جواً فقط) |
| WP | Work Permit | تصريح العمل؛ نوعان: مرتبط بصاحب عمل أو مفتوح |
| SP | Study Permit | تصريح الدراسة |
| PGWP | Post-Graduation Work Permit | تصريح عمل بعد التخرج من مؤسسة كندية مؤهلة |
| LMIA | Labour Market Impact Assessment | تقييم يصدره ESDC يثبت حاجة صاحب العمل لأجنبي؛ برنامج TFWP |
| TFWP | Temporary Foreign Worker Program | مسار تصاريح العمل القائم على LMIA |
| IMP | International Mobility Program | مسار تصاريح العمل المعفاة من LMIA |
| EE | Express Entry | نظام إدارة طلبات الإقامة الدائمة للمهارات |
| CRS | Comprehensive Ranking System | نظام النقاط داخل Express Entry |
| ITA | Invitation to Apply | دعوة التقديم بعد جولة سحب |
| FSW | Federal Skilled Worker Program | برنامج العمال المهرة الفيدرالي (ضمن EE) |
| CEC | Canadian Experience Class | فئة أصحاب الخبرة الكندية (ضمن EE) |
| FST | Federal Skilled Trades Program | برنامج الحِرَف الماهرة (ضمن EE) |
| PNP | Provincial Nominee Program | برامج ترشيح المقاطعات |
| AIP | Atlantic Immigration Program | برنامج هجرة الأطلسي (4 مقاطعات) |
| RCIP | Rural Community Immigration Program | برنامج الهجرة للمجتمعات الريفية (أصبح دائماً نوفمبر 2026) |
| FCIP | Francophone Community Immigration Pilot | تجريبي المجتمعات الفرنكوفونية |
| CSQ | Certificat de sélection du Québec | شهادة اختيار كيبيك؛ إلزامية قبل الطلب الفيدرالي لمن وجهته كيبيك |
| DLI | Designated Learning Institution | مؤسسة تعليمية معتمدة لاستقبال الطلاب الدوليين |
| ECA | Educational Credential Assessment | تقييم معادلة الشهادات الأجنبية (جهات معتمدة مثل WES) |
| CLB/NCLC | Canadian Language Benchmarks | مقياس المستوى اللغوي الكندي الذي تُترجم إليه نتائج الاختبارات |
| NOC | National Occupational Classification | تصنيف المهن الوطني |
| TEER | Training, Education, Experience, Responsibilities | فئات NOC من 0 (إداري/جامعي) إلى 5 (يدوي بسيط) |
| PoF | Proof of Funds | إثبات الأموال المطلوب لبعض البرامج |
| PoE | Port of Entry | نقطة الدخول (مطار/معبر) |
| Biometrics | البصمات والصورة | تُجمع في مراكز VAC؛ تُحفظ 10 سنوات للزيارات/التصاريح |
| VAC | Visa Application Centre | مركز استقبال الطلبات والبصمات (مشغل خاص بتفويض) |
| H&C | Humanitarian and Compassionate | اعتبارات إنسانية استثنائية |
| UNHCR | مفوضية اللاجئين | تحيل حالات إعادة التوطين إلى كندا |
| Super Visa | تأشيرة الوالدين والأجداد | زيارات طويلة تصل إلى 5 سنوات لكل دخول، ليست إقامة دائمة ولا تخول العمل |
| AOR | Acknowledgment of Receipt | إشعار استلام الطلب |
| GCMS Notes | ملاحظات نظام إدارة الحالات | سجل ضابط الهجرة؛ يطلبه البعض لمتابعة طلبه |
| NOC 21300 | مهندسون مدنيون | رمز المهنة في التصنيف الوطني (مثال شائع لطالبي الهندسة المدنية) |
