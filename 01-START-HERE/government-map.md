# خريطة الجهات الحكومية

آخر تحقق: 2026-11-22. الروابط الأساسية؛ التفصيل في بطاقات البرامج.

## فيدرالية

| الجهة | الدور | الموقع |
|---|---|---|
| IRCC | البرامج، التأشيرات، التصاريح، الإقامة الدائمة، الجنسية، أوقات المعالجة، الحساب الإلكتروني | canada.ca/en/immigration-refugees-citizenship |
| IRCC — Processing times | أدوات أوقات المعالجة الرسمية المتغيرة | canada.ca (أداة Check processing times) |
| IRCC — Fee list | جدول الرسوم الرسمي المتغير | canada.ca (أداة Fee list) |
| ESDC / Service Canada | LMIA، شروط توظيف الأجانب، برنامج TFWP للجهات الموظفة | canada.ca/en/employment-social-development |
| Job Bank | بنك الوظائف الحكومي؛ فلتر "Canadian and international candidates" يميز من يقبل من الخارج | jobbank.gc.ca |
| CBSA | الحدود، الوثائق عند الوصول، السلع الممنوعة | cbsa-asfc.gc.ca |
| IRB | اللجوء والاستئناف | irb-cisr.gc.ca |

## جهات مساندة معتمدة (ليست حكومية لكن دورها نظامي)

| الجهة | الدور |
|---|---|
| جهات تقييم الشهادات ECA المعتمدة من IRCC | WES وغيرها؛ تصدر تقارير معادلة الشهادات |
| مقدمو اختبارات اللغة المعتمدون | IELTS، CELPIP، PTE Core (إنجليزية)؛ TEF/TCF Canada (فرنسية) — القائمة الرسمية تُتحقق من صفحة IRCC للغة في مرحلة الأدلة |
| الأطباء المعتمدون (Panel Physicians) | الفحوص الطبية للهجرة حصراً عبرهم |
| مراكز VAC | استلام البصمات والجوازات بتفويض (لا تملك قرار القبول) |
| UNHCR | إحالة حالات إعادة التوطين |
| RCIC / المحامون المرخصون | الاستشارات المدفوعة النظامية؛ التحقق من الترخيص عبر سجل CICC للمستشارين أو نقابات المحاماة |

## قاعدة التحقق الذهبية

أي جهة تطلب منك مالاً أو وثائق: قارن ما تطلبه مع الصفحة الرسمية. الدومين الرسمي للحكومة الفيدرالية هو **canada.ca** وللمقاطعات نطاقاتها الحكومية الموثقة أعلاه. أي رابط آخر يعامل كمصدر ثانوي حتى إثباته.
