# بيانات مرجعية لمحرك القرار

- financial-comparison-data.json — بيانات المقارنة المالية (حزمة التخطيط المالي، 2026-11-22).
- pnp/<id>.json — بيانات برامج المقاطعات المنظمة مقسمة لكل جهة (71 مساراً، 13 جهة؛ المجمع الكامل قُسّم لتجاوز حدود النشر عبر الويب، وسجل الأحكام في pnp/provenance.json)؛ الأحكام الميدانية لكل حقل في pnp-delta وسجل provenance-ledger. لا تُستهلك في قواعد الإقصاء إلا الحقول المؤكدة بتحقق مباشر.
- pnp-delta-sk-mb-qc-2026-11-22.json — أحكام التحقق الأولي حقل-بحقل لساسكاتشوان ومانيتوبا وكيبيك (مؤكد/مُكمل/مُصحح/متجاوَز/غير محقق مع روابط المصادر).
