# خرائط الانتقال بين الأوضاع

آخر تحديث: 2026-11-22 — الإطار + المسارات الأربعة النموذجية بما هو موثق اليوم. كل سهم يُكمل بحقوله الستة (شروط، مدة، قيود، مستندات، مخاطر، بدائل) من بطاقات 03 عند اكتمالها.

## المفتاح

`[وضع] —شرط القفزة→ [وضع]`. ⚠ = قفزة غير مضمونة تعتمد على قرار طرف آخر أو منافسة.

## خريطة 1: العمل ← الإقامة (المسار التشغيلي الرئيسي من الخارج)

```
خارج كندا
  —عرض عمل حقيقي + LMIA لصاحب العمل أو إعفاء IMP موثق ⚠→ تصريح عمل مرتبط بصاحب عمل
  —موافقة IRCC + خطاب POE + قبول ضابط الحدود ⚠→ الدخول والعمل
  —12 شهراً خبرة كندية TEER 0-3 → أهلية CEC (وفئات "بخبرة كندية")
  —أو: ملف FSW أصلاً + نقاط أعلى بالخبرة الكندية/العرض عالي الأجر → ITA ⚠→ إقامة دائمة
```
- قيود موثقة: التصريح المرتبط يقيّد تغيير صاحب العمل (تصريح جديد لكل انتقال). الموافقة على التصريح ليست ضماناً لأي PR.
- بدائل عند تعثر LMIA: صاحب عمل معتمد AIP/RCIP (لا يحتاج LMIA لمسار الإقامة نفسه).

## خريطة 2: الإقامة الدائمة المباشرة عبر Express Entry

```
خارج كندا —اختبار لغة + ECA + ملف EE→ المجموعة —ITA (عام/برنامجي/فئوي) ⚠→ طلب PR خلال 60 يوماً → إقامة دائمة
```
- شروط القفزة الأولى موثقة في بطاقة FSW. الجولات موقوفة مؤقتاً من 2026-11-03 (إعادة حساب CRS).
- فئة STEM الحالية تضم المهندسين المدنيين (21300) والخبرة الخارجية تحتسب (12 شهراً/3 سنوات/مهنة واحدة) — S23.

## خريطة 3: الترشيح الإقليمي

```
خارج كندا —أهلية مسار مقاطعة ⚠→ ترشيح —معزز بـEE: ‎+600 نقطة→ ITA ⚠→ PR
                              —غير معزز: طلب PR فيدرالي مباشر ⚠→ PR
```
- قيد موثق: المُرشَّح يستقر في المقاطعة المرشِّحة (صفحة FSW تؤكد الالتزام).
- بطاقات المسارات لكل مقاطعة: حزمة WP-A قيد البحث.

## خريطة 4: الدراسة

```
خارج كندا —قبول DLI + إثبات مالي + تصريح دراسة ⚠→ طالب —تخرج من برنامج مؤهل ⚠→ PGWP —خبرة كندية→ CEC/فئات ⚠→ PR
```
- قيود موثقة: تغيير المدرسة يستلزم تصريحاً جديداً منذ 2024-11-08. PGWP مشروط بأهلية المؤسسة/البرنامج (تفاصيل 2026: حزمة WP-D).
- تحذير مالي: أعلى مسارات التكلفة؛ غير واقعي بميزانية صفر إلا بمنحة كاملة موثقة.

## ما لا يوجد له سهم (حدود المنظومة الموثقة)

- زائر ↛ عمل: لا تحويل نظامي من زيارة إلى عمل من الداخل كمسار عام؛ أي استثناء مؤقت يُوثق بحالته وتاريخه قبل اعتماده.
- لجوء ↛ "مسار هجرة": إجراء حماية مستقل بمعاييره؛ لا يُستخدم قفزة اقتصادية.
- عرض عمل ↛ ضمان تصريح: كل سهم ⚠ قرار مستقل.
