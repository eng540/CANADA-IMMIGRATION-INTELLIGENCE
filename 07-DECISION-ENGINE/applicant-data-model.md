# نموذج بيانات المتقدم (المدخلات)

كل حقل: الاسم، النوع، لماذا يُسأل (القواعد التي يغذيها). حقول "غير معروف" قيمة مشروعة تُبقي المسار "محتملاً".

## الهوية والوضع الحالي

| الحقل | النوع | يغذي |
|---|---|---|
| الجنسية | نص (دولة) | أهلية eTA/TRV، IEC، فئات خاصة ببلدان |
| بلد الإقامة الحالي | نص | متطلبات الفحص الطبي/البصمات، مكاتب المعالجة |
| الوضع القانوني في بلد الإقامة | نظامي/غير نظامي/منتهٍ | متطلبات التقديم من بلد الإقامة، مخاطر |
| جواز ساري + تاريخ انتهائه | منطقي + تاريخ | جوهر كل تقديم |
| أقارب في كندا (صلة القرابة ووضعهم) | قائمة | نقاط تكيّف FSW، كفالات، بعض PNP |
| خبرة/دراسة سابقة في كندا | منطقي + تفاصيل | CEC، فئات "بخبرة كندية"، نقاط |

## المؤهلات والخبرة

| الحقل | النوع | يغذي |
|---|---|---|
| أعلى مؤهل + التخصص + بلد وجامعة التخرج | نصوص | ECA، نقاط التعليم، متطلبات المهن المنظمة |
| سنوات الخبرة لكل مهنة (NOC إن أمكن) + تواريخها | جدول | FSW/CEC/FST، فئات EE، PNP |
| المهنة الأساسية المقصودة | NOC | مطابقة الفئات (12 شهراً في مهنة واحدة خلال 3 سنوات) |
| هل المهنة منظمة في كندا وتحتاج ترخيصاً؟ | مشتق من NOC | جدية عرض العمل، زمن الوصول للعمل الفعلي |
| اللغة: مستوى إنجليزية/فرنسية + نتائج اختبار إن وجدت | تقدير + درجات | أهلية اللغة، الفئة الفرنسية (NCLC 7)، نقاط CRS |
| شهادات حِرَف/تراخيص مهنية | قائمة | FST، الترخيص الإقليمي |

## الأسرة والمال

| الحقل | النوع | يغذي |
|---|---|---|
| الحالة الاجتماعية + عدد الأبناء وأعمارهم | نص + جدول | إثبات الأموال (حجم الأسرة)، الكفالات، اصطحاب الأسرة |
| الميزانية المتاحة للمسار كاملاً | مبلغ بعملة محددة | الخطوة الرابعة (القدرة المالية)، سيناريوهات 08 |
| وجود عرض عمل حالي + تفاصيله | منطقي + تفاصيل | مسارات العمل، إعفاء الأموال، نقاط العرض |

## التفضيلات

| الحقل | النوع | يغذي |
|---|---|---|
| الاستعداد لأي مقاطعة | نعم/لا + استثناءات | PNP، AIP، RCIP/FCIP |
| الاستعداد لمجتمعات صغيرة | نعم/لا | RCIP/FCIP |
| الاستعداد للدراسة | نعم/لا | مسار الدراسة |
| أفق زمني مقبول | أشهر | وزن زمن المعالجة في الترتيب |

## قواعد جودة الإدخال

- لا افتراضات: الحقل الفارغ = غير معروف، ويظهر في المخرجات كمعلومة ناقصة.
- كل إجابة يمكن تحديثها وإعادة تشغيل المحرك دون إعادة إدخال الباقي.

## مطابقة المدخلات مع المحرك المباشر (فحص مطابقة 2026-11-22)

كل مدخل من النموذج أعلاه إما منفذ كحقل في [نموذج المحرك](engine.md) أو مُسند صراحة لفحص يدوي موثق. المحرك يقيم 74 مساراً من نحو 20 حقل إدخال؛ هذه المطابقة تبين أين يقع كل مدخل من النموذج:

| مدخل النموذج | أين يُعالج اليوم |
|---|---|
| الجنسية | **لا حقل له في المحرك — فحص يدوي إلزامي**: تأثير الجنسية مقصور على eTA/TRV، اتفاقيات IEC، والتدابير الخاصة؛ كلها بنود «فحص يدوي» في نتائج المحرك و[سجل الفحوص](manual-checks.md) |
| بلد الإقامة الحالي والوضع القانوني فيه | **لا حقل — فحص يدوي**: يؤثر في مكان البصمات/الفحص الطبي ومخاطر التقديم من إقامة غير نظامية، لا في أهلية المسارات ذاتها |
| جواز ساري وتاريخه | قائمة مستندات يدوية (دليل المستندات، الخطوة الثانية) |
| أقارب في كندا | حقل «قريب مواطن/مقيم دائم» |
| خبرة/دراسة سابقة في كندا | حقول «سنوات خبرة العمل في كندا» + «فئة TEER» + «مقاطعة الخبرة»؛ نقاط الدراسة الكندية غير محسوبة (تحذير «النقاط تقريبية» يغطيها) — مراجعة يدوية عند المقارنة النهائية |
| أعلى مؤهل + ECA | حقلا «أعلى مؤهل» و«تقييم ECA» |
| سنوات الخبرة والمهنة | حقل «سنوات خبرة أجنبية ماهرة» + «فئة TEER لمهنتك الأساسية» + «القطاع» — **تحفظ جوهري: اختيار TEER/قطاع ليس مطابقة NOC دقيقة**؛ المطابقة الدقيقة فحص يدوي عبر [باني ملف NOC](noc-profile-builder.md) وأدوات NOC في أدلة العمل، وقواعد القوائم (قائمة الثمانية RCIP، قوائم المهن الإقليمية) تُرجع «يحتاج تحققاً رسمياً» دائماً ولا تستبعد أحداً |
| هل المهنة منظمة؟ | فحص يدوي عبر [المهن المنظمة](../09-EMPLOYMENT/regulated-professions.md) |
| اللغة | حقلا «أدنى مهارة إنجليزية» و«أدنى مهارة فرنسية» |
| شهادات حِرَف | حقلا «شهادة تأهيل حرفة كندية» و«مهنة FST مؤهلة» |
| الحالة الاجتماعية والأبناء | حقل «حجم الأسرة» (إثبات الأموال)؛ أعمار المعالين وأهلية اصطحابهم فحص يدوي (حقل الأسرة في بطاقات البرامج) |
| الميزانية | حقل «إثبات الأموال» (سقف حجم الأسرة)؛ الميزانية الكلية عبر [حاسبة التكاليف](../05-COSTS-AND-FEES/cost-calculator.md) وسيناريوهات 08 |
| عرض عمل حالي | حقول «عرض عمل مدعوم» + «صاحب عمل مخصص» + «مقاطعة عرض العمل» |
| الاستعداد لأي مقاطعة / مجتمعات صغيرة | **لا حقول استبعادية**: المحرك يقيم كل المسارات الإقليمية والمجتمعية ويرتبها بقابلية التنفيذ؛ الاستعداد مرشح تفضيلات يطبقه المستخدم يدوياً عند المقارنة (هذا مقصود: لا نُخفي مساراً مؤهلاً لأن التفضيل قد يتغير) |
| الاستعداد للدراسة | حقل «خطاب قبول من مؤسسة DLI» (واقع فعلي)؛ الاستعداد النظري عبر [سيناريوهات 08](../08-SCENARIOS/README.md) وخرائط التحول |
| الأفق الزمني | لا حقل؛ مدد المعالجة ظاهرة في كل بطاقة برنامج وتُقارن يدوياً |

**قاعدة ثابتة**: الحقول غير المنفذة لا تعني إهمالها — كل واحد منها إما فحص يدوي موثق في المخرجات أو مرشح تفضيلات مقصود عدم أتمتته. أي حكم استبعاد في المحرك هو تقييم للملف الحالي المدخل، لا حكم أهلية دائم.
