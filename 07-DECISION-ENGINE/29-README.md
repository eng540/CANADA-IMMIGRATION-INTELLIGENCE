## مبادئ التصميم

1. **لا قاعدة بلا بطاقة موثقة**: كل قاعدة استبعاد/أهلية تشير إلى رقم حقل في بطاقة برنامج ومصدره وتاريخه.
2. **ثلاث نتائج فقط لكل مسار**: مؤهل / محتمل — يحتاج معلومة / غير مؤهل — سبب الاستبعاد. لا نسب نجاح رقمية دون بيانات رسمية (جولات EE السابقة هي المصدر الوحيد المقبول لأي تقدير تنافسي، وتُذكر بتاريخها).
3. **المجهول لا يستبعد**: نقص معلومة (مثل مستوى فرنسية غير معروف) يضع المسار في "محتمل" مع ذكر المعلومة الناقصة، لا في "غير مؤهل".
4. **التكلفة محور قرار**: الخطوة الرابعة (القدرة المالية) تعتمد جداول 08-FINANCIAL-PLANNING الموثقة.
5. **قابلية التدقيق**: تشغيل المحرك على حالة يخرج تقريراً يشرح لماذا أُقصي كل مسار، بمراجعة البطاقات.
