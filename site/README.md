# site/ — إعدادات موقع الدليل

المحتوى نفسه يعيش في جذر المستودع (الأدلة الـ13). هذا المجلد يحوي فقط:

- `mkdocs.yml` — إعداد MkDocs Material (عربي RTL، بحث، خريطة تنقل كاملة).
- `assets/extra.css` — تحسينات خطوط ومحاذاة عربية.

## البناء والمعاينة

```bash
pip install mkdocs-material
cd site
mkdocs serve    # معاينة محلية
mkdocs build    # ينتج ../kb-site-build/ الثابت (خارج المستودع، لا يُرفع)
```

## قواعد

- أي ملف `.md` جديد في جذر المستودع يُضاف إلى `nav` هنا ليظهر في القوائم (البحث يلتقطه تلقائياً حتى دون nav، لكن التنقل المنظم شرط للاحترافية).
- `03-ALL-PROGRAMS/card-template.md` مستبعد من الموقع (قالب داخلي للمؤلفين، ليس محتوى للقارئ).
- عند النشر العام لاحقاً: GitHub Pages من `mkdocs gh-deploy` بعد فصل البيانات الشخصية (قرار النشر وضماناته في سجل القرارات الرئيسي).
