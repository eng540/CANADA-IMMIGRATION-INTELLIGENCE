# CANADA ENTRY, IMMIGRATION & EMPLOYMENT KNOWLEDGE BASE
# الموسوعة الشاملة للدخول إلى كندا والعمل والإقامة والاستقرار

مستودع معرفي عملي لشخص موجود خارج كندا يريد فهم جميع الخيارات القانونية المتاحة أمامه للدخول إلى كندا، بإقامة مؤقتة أو دائمة، والعمل والاستقرار وفق شروط كل برنامج.

> **تنبيه**: هذا المستودع مرجع معلوماتي مبني على مصادر حكومية كندية رسمية، وليس استشارة قانونية أو وعداً بقبول أو وظيفة. القواعد تتغير؛ لكل معلومة تاريخ تحقق ورابط مصدر، فراجع المصدر قبل أي قرار.

## قواعد المعلومات المعتمدة

1. المصادر الحكومية الكندية الرسمية هي المرجع الأول: IRCC، ESDC، Job Bank، مواقع المقاطعات الرسمية.
2. المصادر الثانوية للتفسير والمقارنة فقط، وتُوسم بوصفها ثانوية.
3. لا توصف حالة برنامج (مفتوح/متوقف/مغلق) دون تحقق من وضعه الحالي بتاريخ موثق.
4. الفصل الصارم بين: معلومة مؤكدة بمصدر / استنتاج / توقع.
5. لا خلط بين التأشيرة (Visa) وتصريح العمل (Work Permit) والإقامة الدائمة (PR).
6. لا وعود بوظيفة أو قبول، ولا نِسَب نجاح دون بيانات إحصائية.
7. الزيارة ليست عملاً؛ عرض العمل ليس ضماناً لتصريح أو إقامة؛ اللجوء ليس وسيلة هجرة اقتصادية.
