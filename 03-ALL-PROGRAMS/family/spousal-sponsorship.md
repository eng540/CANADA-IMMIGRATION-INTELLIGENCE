> **مصدر هذا الملف**: حزمة بحث «الدراسة والأسرة والحماية والأعمال» — النسخة المنقحة الثانية (استرجاع 2026-11-22)، راجعها مالك التكامل وتحقق من بنودها المحسوبة من مصادرها الرسمية قبل دمجها في هذا المستودع. روابط المصادر مضمنة في النص كما وردت. البطاقات بصيغة جداول الحزمة وتُستكمل لاحقاً نحو قالب الـ25 حقلاً الكامل حيث نقصت حقول.

### 4.1 بطاقة: كفالة الزوج/الشريك والأطفال المعالين

| الحقل | القيمة |
|---|---|
| الاسم الرسمي | Spouse, Partner or Dependent Children Sponsorship |
| الجهة المالكة | IRCC |
| النوع | إقامة دائمة — عائلة |
| الكفيل | مواطن كندي أو مقيم دائم ≥18 سنة، مقيم في كندا (المواطن قد يكفل من الخارج بشرط نية العودة)، غير متلقٍ لإعانات اجتماعية (باستثناء الإعاقة)، دون تعهدات سابقة متعثرة |
| المكفول | زوج/زوجة، شريك عرفي (common-law)، شريك زواجي (conjugal)، أطفال معالون |
| المسارات | داخل كندا (مع إمكان تصريح عمل مفتوح) أو خارج كندا |
| هدف 2027–2029 | 66,000 سنوياً لهذه الفئة؛ الهدف المعلن: معالجة قريبة من **12 شهراً** لفئة الأزواج خارج كيبيك عبر الإجراء المؤقت الجديد |
| الجنسية/العمر/التعليم/الخبرة/اللغة/عرض العمل/LMIA | لا متطلبات للمكفول |
| الأموال | لا حد أدنى للدخل لفئة الأزواج/الأطفال (يمنع تلقي الإعانات)؛ التعهد المالي 3 سنوات للزوج و10 سنوات للطفل المعال |
| الرسوم | رسوم كفالة + معالجة + حق الإقامة الدائمة (تحقق من القائمة الرسمية) |
| الطبي/الأمني | فحص طبي + شهادات حسن سيرة للمكفول |
| المستندات | إثبات علاقة حقيقية (زواج/سكن مشترك/مراسلات)، نماذج الكفالة والتعهد |
| التحول | هو نفسه إقامة دائمة |
| أسباب الرفض | علاقة غير حقيقية (زواج مصلحة)، عدم أهلية الكفيل، عدم قبول أمني/طبي |
| ملاحظة | ضحايا العنف الأسري لديهم خيارات حماية خاصة |
| المصدر | الرابط العام أعلاه |
