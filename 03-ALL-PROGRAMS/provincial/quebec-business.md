### 7.3 كيبيك للأعمال (مستثمر/رائد/عامل لحسابه)

المصدر: [Quebec business: Who can apply](https://www.canada.ca/en/immigration-refugees-citizenship/services/immigrate-canada/quebec-business/eligibility.html) (استرجاع 22-11-2026).

| الحقل | القيمة |
|---|---|
| الاسم الرسمي | Quebec Investors / Entrepreneurs / Self-Employed (مسارات كيبيك للأعمال) |
| الجهة المالكة | MIFI (الاختيار، شهادة CSQ) ثم IRCC (الإقامة الدائمة) |
| النوع | إقامة دائمة — أعمال إقليمية |
| الأهلية من خارج كندا | نعم |
| الجنسية | مفتوح |
| العمر/التعليم/الخبرة/اللغة | تختلف باختلاف المسار على موقع كيبيك الرسمي؛ **تفاصيل دقيقة لم تُسترجع — مجهول صراحة هنا** |
| عرض عمل | غير مطلوب (مشروع/استثمار بدلاً منه) |
| LMIA | غير مطلوب |
| الأموال | متطلبات أصول/استثمار خاصة بكيبيك لكل مسار (تحقق من MIFI) |
| الرسوم | رسوم كيبيك + رسوم فيدرالية |
| الطبي/الأمني | ينطبق فيدرالياً |
| المستندات | ملف MIFI ثم حزمة PR فيدرالية |
| التقديم | إلى MIFI وفق برنامج الحالة؛ [بوابة كيبيك](https://www.quebec.ca/en/immigration/permanent/immigrate-business/investors/applying) |
| المراحل | CSQ → طلب PR فيدرالي → قرار |
| أوقات المعالجة | متغيرة — أداة IRCC وMIFI |
| المرافقون | الأسرة ضمن الطلب |
| حقوق العمل/الدراسة | بعد PR |
| التحول إلى PR | هو مسار PR |
| أسباب الرفض | عدم استيفاء شروط المسار أو القبول الفيدرالي |
| المخاطر | حصص كيبيك في خطة 2027–2029 موسومة **TBD** بانتظار خطة كيبيك (خريف 2026) — **مجهول صراحة** عند الاسترجاع |
| آخر تحديث | لم يُسترجع تغيير 2026 محدد |
| المصدر | [Quebec business: Who can apply](https://www.canada.ca/en/immigration-refugees-citizenship/services/immigrate-canada/quebec-business/eligibility.html) (استرجاع 22-11-2026) |
