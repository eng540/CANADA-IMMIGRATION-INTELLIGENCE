# بطاقة: تصريح الدراسة (Study Permit)

> **مصدر هذا الملف**: حزمة بحث «الدراسة والأسرة والحماية والأعمال» — النسخة المنقحة الثانية (استرجاع 2026-11-22)، راجعها مالك التكامل وتحقق من بنودها المحسوبة من مصادرها الرسمية قبل دمجها في هذا المستودع. روابط المصادر مضمنة في النص كما وردت. البطاقات بصيغة جداول الحزمة وتُستكمل لاحقاً نحو قالب الـ25 حقلاً الكامل حيث نقصت حقول.

---

### 2.2 بطاقة برنامج: تصريح الدراسة

| الحقل | القيمة |
|---|---|
| الاسم الرسمي | Study Permit (تصريح دراسة) |
| الجهة المالكة | IRCC (وCAQ من MIFI لكيبيك) |
| النوع | إقامة مؤقتة — دراسة |
| الأهلية من خارج كندا | نعم (المسار الأساسي) |
| الجنسية | مفتوح لجميع الجنسيات |
| العمر | لا حد أعلى؛ القاصرون دون 17 يحتاجون ولي/وصي في كندا |
| التعليم | خطاب قبول LOA من DLI (تتحقق المؤسسة منه) |
| الخبرة | غير مطلوبة |
| اللغة | حسب متطلبات قبول المؤسسة (لا حد IRCC مباشر للتصريح) |
| عرض عمل | غير مطلوب |
| LMIA | غير مطلوب |
| الأموال | إثبات رسوم دراسية + معيشة: **$23,448** سنوياً لفرد واحد (للطلبات من 1-9-2026؛ قبلها $22,895) + $~6,300 لكل مرافق إضافي (كيبيك: حسب متطلبات MIFI) — [المصدر](https://www.canada.ca/en/immigration-refugees-citizenship/services/study-canada/study-permit/get-documents/financial-support.html) |
| الرسوم | تصريح دراسة $150 + بيومترics $85 عند الحاجة (تحقق من قائمة الرسوم الرسمية) |
| الطبي/الأمني | فحص طبي عند الإقامة >6 أشهر أو حسب بلد الإقامة؛ شهادة حسن سيرة عند الطلب |
| المستندات | LOA + PAL/TAL (أو إعفاء) + جواز + إثبات أموال + خطاب تفسيري + مستندات المكتب القنصلي المحلي |
| التقديم | إلكتروني عبر حساب IRCC الآمن |
| المراحل | تقديم → بيومترics → معالجة → قرار → تسليم التصريح عند الوصول |
| أوقات المعالجة المنشورة | متغيرة حسب البلد؛ تُنشر في أداة IRCC لأوقات المعالجة (لم تُسترجع أرقام ثابتة — تحقق مباشرة) |
| المرافقون | الزوج/الشريك والأطفال المعالون يمكنهم المرافقة (قيود جديدة على تصاريح عمل المرافقين منذ 2024 — تحقق من الصفحة الرسمية) |
| حقوق العمل/الدراسة | عمل خارج الحرم حتى **24 ساعة/أسبوع** أثناء الفصول، وساعات غير محدودة في الإجازات المجدولة؛ يشترط SIN وشروط مطبوعة على التصريح |
| التحول إلى PR | غير مضمون؛ مسارات شائعة: PGWP ثم Express Entry (فئة الخبرة الكندية) أو PNP |
| أسباب الرفض الشائعة | أموال غير كافية، شك في نية الدراسة الحقيقية، وثائق ناقصة، عدم إقناع بمغادرة كندا عند انتهاء الوضع |
| المخاطر | السقف يقلل الأماكن؛ تجاوز 24 ساعة عمل = فقدان وضع الطالب؛ تغييرات PAL سنوية |
| آخر تحديث | تخصيصات 2026 (25-11-2025) وإعفاء الماجستير/الدكتوراه من PAL (1-1-2026) |
| المصدر | [صفحة تصريح الدراسة](https://www.canada.ca/en/immigration-refugees-citizenship/services/study-canada/study-permit.html) (استرجاع 22-11-2026) |
