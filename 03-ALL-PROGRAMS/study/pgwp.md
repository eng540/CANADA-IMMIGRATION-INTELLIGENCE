> **مصدر هذا الملف**: حزمة بحث «الدراسة والأسرة والحماية والأعمال» — النسخة المنقحة الثانية (استرجاع 2026-11-22)، راجعها مالك التكامل وتحقق من بنودها المحسوبة من مصادرها الرسمية قبل دمجها في هذا المستودع. روابط المصادر مضمنة في النص كما وردت. البطاقات بصيغة جداول الحزمة وتُستكمل لاحقاً نحو قالب الـ25 حقلاً الكامل حيث نقصت حقول.

### 2.3 بطاقة برنامج: تصريح عمل ما بعد التخرج PGWP

المصادر: [PGWP: Who can apply](https://www.canada.ca/en/immigration-refugees-citizenship/services/study-canada/work/after-graduation/eligibility.html) و[تحديث شرط مجال الدراسة](https://www.canada.ca/en/immigration-refugees-citizenship/news/notices/update-requirement-post-graduation-work-permits.html) (استرجاع 22-11-2026).

| الحقل | القيمة |
|---|---|
| الاسم الرسمي | Post-Graduation Work Permit (PGWP) |
| الجهة المالكة | IRCC |
| النوع | تصريح عمل مفتوح بعد التخرج (مرة واحدة في العمر) |
| الأهلية من خارج كندا | ممكنة (خريجون من الخارج ضمن شروط التعلم عن بُعد أو بعد مغادرة كندا) |
| الجنسية | مفتوح |
| العمر | لا قيد |
| التعليم | إتمام برنامج ≥8 أشهر (أو 900 ساعة لكيبيك) في DLI مؤهل لـPGWP، بدوام كامل |
| الخبرة | غير مطلوبة |
| اللغة | **CLB/NCLC 7** لخريجي الجامعات (بكالوريوس/ماجستير/دكتوراه وبرامج جامعية أخرى)؛ **CLB/NCLC 5** لخريجي الكليات والمعاهد — للطلبات من 1-11-2024 فصاعداً |
| عرض عمل | غير مطلوب |
| LMIA | غير مطلوب |
| الأموال | لا حد منشور محدد |
| الرسوم | $155 تصريح عمل + $100 رسوم التصريح المفتوح + بيومترics عند الحاجة |
| الطبي/الأمني | قد يُطلب فحص طبي لبعض الوظائف |
| المستندات | إثبات إتمام البرنامج، كشف درجات، نتيجة لغة، جواز |
| التقديم | خلال **180 يوماً** من تأكيد إتمام البرنامج، وكان تصريح الدراسة سارياً خلال تلك الفترة |
| المراحل | تقديم إلكتروني → قرار |
| أوقات المعالجة | متغيرة — أداة IRCC الرسمية |
| المرافقون | أفراد الأسرة حسب قواعد التصاريح المفتوحة المرافقة (تشددت منذ 2025 — تحقق) |
| حقوق العمل | عمل غير مقيد بصاحب عمل؛ بعد التخرج يمكن العمل بدوام كامل أثناء انتظار القرار إذا قُدم الطلب قبل انتهاء تصريح الدراسة |
| التحول إلى PR | الخبرة الكندية المكتسبة تدعم Express Entry/PNP — **غير مضمون** |
| شرط مجال الدراسة | لمن قدّم طلب تصريح الدراسة **في/بعد 1-11-2024** في برامج غير البكالوريوس/الماجستير/الدكتوراه: التخرج في مجال مؤهل مرتبط بنقص طويل الأمد. القائمة الحالية **920 مجالاً** (تحديث 4-7-2025: أُضيف 119 مجالاً وحُذف 178). لا شرط مجال لحاملي الشهادات الجامعية (بكالوريوس فأعلى) |
| المخاطر | تغيّر قائمة المجالات؛ برامج الترخيص المنهجي بين الكليات العامة والخاصة غير مؤهلة غالباً (من بدأ بعد 15-5-2024 ضمن نفس المقاطعة غير مؤهل)؛ قواعد التعلم عن بُعد (≥50% حضورياً داخل كندا لمن بدأ من 1-9-2024) |
| آخر تحديث | تحديث CIP في 4-7-2025 |
| المصدر | الروابط أعلاه (استرجاع 22-11-2026) |
