# 03 — سجل جميع البرامج (ALL PROGRAMS)

آخر تحديث: 2026-11-22 — بطاقات المسارات الفيدرالية الثلاثة بالقالب الكامل (25 حقلاً)، و71 بطاقة مسار إقليمي بحقول القالب الكاملة (غير الموثق منها موسوم صراحة) في [provincial](provincial/README.md) (S137/S138) يقيّمها [محرك القرار](../07-DECISION-ENGINE/engine.md) معياراً بمعيار. الأقسام الأخرى (عائلة، حماية، إقليمية، خاصة، دراسة، زيارة) بحسب ملفات أقسامها، وما لم تُبنَ بطاقته بعد يُذكر صراحة.

## تصنيفات الحالة المعتمدة

`مفتوح` · `مفتوح بشروط/حصص` · `متوقف مؤقتاً` · `مغلق` · `معلن ولم يبدأ` · `غير مؤكد — يحتاج تحقق`
