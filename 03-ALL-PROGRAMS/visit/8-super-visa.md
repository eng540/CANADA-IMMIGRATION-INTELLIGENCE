### 3.3 بطاقة برنامج: التأشيرة الفائقة للوالدين والأجداد (Super Visa)

المصادر: [Super visa: Who can apply](https://www.canada.ca/en/immigration-refugees-citizenship/services/visit-canada/parent-grandparent-super-visa/eligibility.html) و[إثبات الدعم المالي](https://www.canada.ca/en/immigration-refugees-citizenship/services/visit-canada/parent-grandparent-super-visa/forms-documents/host-financial-support.html) (محدث 29-7-2025، استرجاع 22-11-2026).

| الحقل | القيمة |
|---|---|
| الاسم الرسمي | Parent and Grandparent Super Visa |
| الجهة المالكة | IRCC |
| النوع | زيارة طويلة متعددة الدخول: إقامة حتى **5 سنوات** متواصلة لكل دخول، صلاحية حتى 10 سنوات |
| الأهلية من خارج كندا | إلزامي: التقديم والتأشيرة من خارج كندا |
| الجنسية/العمر | مفتوح؛ يشمل المعفين من التأشيرة (يُصدر لهم خطاب) |
| التعليم/الخبرة/اللغة | لا متطلبات |
| عرض عمل/LMIA | غير منطبق |
| الأموال | دخل المضيف (ابن/حفيد كندي مواطن أو دائم أو "هندي مسجل" ≥18 سنة) ≥ الحد الأدنى (جدول 29-7-2025): فردان $38,002؛ 3 أفراد $46,720؛ 4 أفراد $56,724؛ 5 أفراد $64,336؛ 6 $72,560؛ 7 $80,784 (+$8,224 لكل إضافي). خياران للإثبات: دخل كامل ≥ الحد في إحدى آخر سنتين ضريبيتين، أو ≥75% منه في السنة السابقة مع إضافة دخل مقدم الطلب للتكملة |
| الرسوم | $100 + بيومترics $85 |
| الطبي/الأمني | فحص طبي إلزامي + تأمين صحي خاص ≥سنة من شركة كندية أو شركة خارجية معتمدة من الوزير |
| المستندات | خطاب دعوة موقع، إثبات القرابة، إشعارات تقييم CRA للمضيف، إثبات التأمين |
| التقديم/المراحل | إلكتروني من الخارج → بيومترics → قرار |
| المرافقون | الزوج/الشريك يمكن تضمينه |
| حقوق العمل/الدراسة | غير مسموح العمل |
| التحول إلى PR | لا تحويل مباشر؛ بديل الإقامة الدائمة هو PGP (متوقف حالياً — انظر 4.2) |
| أسباب الرفض | دخل المضيف دون الحد، تأمين غير مستوفٍ، شك في المغادرة |
| آخر تحديث | تعليمات وزارية 2026 غيّرت طريقة احتساب الدخل؛ تحديث جدول الدخل 29-7-2025 |
| المصدر | الروابط أعلاه (استرجاع 22-11-2026) |
