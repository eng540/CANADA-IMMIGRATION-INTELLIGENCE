# بطاقة: زائر الأعمال

> **مصدر هذا الملف**: حزمة بحث «الدراسة والأسرة والحماية والأعمال» — النسخة المنقحة الثانية (استرجاع 2026-11-22)، راجعها مالك التكامل وتحقق من بنودها المحسوبة من مصادرها الرسمية قبل دمجها في هذا المستودع. روابط المصادر مضمنة في النص كما وردت. البطاقات بصيغة جداول الحزمة وتُستكمل لاحقاً نحو قالب الـ25 حقلاً الكامل حيث نقصت حقول.

### 3.2 بطاقة برنامج: زائر أعمال (Business Visitor)

المصادر: [Business visitors attending meetings, events and conferences](https://www.canada.ca/en/immigration-refugees-citizenship/services/visit-canada/business/visitors-events-conferences.html) و[مركز مساعدة IRCC](https://ircc.canada.ca/english/helpcentre/answer.asp?qnum=434) (استرجاع 22-11-2026).

| الحقل | القيمة |
|---|---|
| الاسم الرسمي | Business Visitor (فئة ضمن الإقامة المؤقتة) |
| الجهة المالكة | IRCC |
| النوع | دخول لأنشطة أعمال دولية **دون دخول سوق العمل الكندي**: اجتماعات، مؤتمرات، تفاوض، زيارات مواقع، شراء لجهة أجنبية، تدريب داخلي؛ الدخل الرئيسي ومكان العمل يبقيان خارج كندا |
| الأهلية من خارج كندا | نعم (أساسي) |
| الجنسية | مفتوح؛ TRV أو eTA حسب الجنسية |
| العمر/التعليم/الخبرة/اللغة | لا متطلبات رسمية |
| عرض عمل | لا؛ يُمنع العمل لجهة كندية أو تقاضي أجر من مصدر كندي |
| LMIA | غير منطبق |
| الأموال | إثبات قدرة على تكاليف الزيارة |
| الرسوم | TRV $100 أو eTA $7 + بيومترics $85 عند الحاجة |
| الطبي/الأمني | حسب المدة والحالة |
| المستندات | جواز، غرض الزيارة (خطاب دعوة/تسجيل مؤتمر)، أموال، روابط بالوطن |
| التقديم | إلكتروني كطلب زيارة |
| المراحل | كتأشيرة الزيارة |
| أوقات المعالجة | **مجهول صراحة:** لا أرقام منشورة منفصلة لزوّار الأعمال؛ ضمن أوقات TRV بأداة IRCC |
| المرافقون | طلبات مستقلة |
| حقوق العمل/الدراسة | لا تصريح عمل لزائر الأعمال الحقيقي؛ أي نشاط يتجاوز التعريف يتطلب تصريح عمل |
| التحول إلى PR | لا تحويل مباشر |
| أسباب الرفض | شك في طبيعة النشاط (دخول فعلي لسوق العمل)، أموال/روابط ضعيفة |
| المخاطر | تجاوز حدود الفئة = عمل غير مصرح |
| آخر تحديث | لا تغييرات 2026 محددة مسترجعة |
| المصدر | الروابط أعلاه (استرجاع 22-11-2026) |
