> **مصدر هذا الملف**: حزمة بحث «الدراسة والأسرة والحماية والأعمال» — النسخة المنقحة الثانية (استرجاع 2026-11-22)، راجعها مالك التكامل وتحقق من بنودها المحسوبة من مصادرها الرسمية قبل دمجها في هذا المستودع. روابط المصادر مضمنة في النص كما وردت. البطاقات بصيغة جداول الحزمة وتُستكمل لاحقاً نحو قالب الـ25 حقلاً الكامل حيث نقصت حقول.

### 3.1 بطاقة برنامج: تأشيرة زيارة (TRV)

المصدر: [How to apply for a visitor visa](https://www.canada.ca/en/immigration-refugees-citizenship/services/visit-canada/apply-visitor-visa.html) (استرجاع 22-11-2026).

| الحقل | القيمة |
|---|---|
| الاسم الرسمي | Temporary Resident Visa (Visitor Visa) |
| الجهة المالكة | IRCC |
| النوع | إقامة مؤقتة — زيارة (عادة حتى 6 أشهر لكل دخول) |
| الأهلية من خارج كندا | نعم (أساسي) |
| الجنسية | مواطنو الدول المعفاة يحتاجون eTA فقط؛ السعودية ومعظم الدول العربية تحتاج TRV |
| العمر/التعليم/الخبرة/اللغة | لا متطلبات رسمية |
| عرض عمل/LMIA | غير منطبق (العمل ممنوع) |
| الأموال | إثبات قدرة مالية للزيارة (لا حد رقمي منشور) |
| الرسوم | $100 + بيومترics $85 |
| الطبي/الأمني | حسب الحالة والمدة |
| المستندات | جواز، صور، إثبات أموال، غرض الزيارة، روابط بالوطن |
| التقديم/المراحل | إلكتروني → بيومترics → قرار → ختم التأشيرة |
| أوقات المعالجة | متغيرة حسب البلد — أداة IRCC |
| المرافقون | كل فرد طلب مستقل |
| حقوق العمل/الدراسة | **ممنوع العمل**؛ دراسة قصيرة ≤6 أشهر مسموحة |
| التحول إلى PR | لا يوجد تحويل مباشر؛ تمديد الإقامة عبر Visitor Record |
| أسباب الرفض | الشك في نية المغادرة، أموال/روابط ضعيفة، غرض غير مقنع |
| المخاطر/آخر تحديث/المصدر | تدقيق متزايد ضمن خفض المقيمين المؤقتين؛ الرابط أعلاه (استرجاع 22-11-2026) |
