### 4.2 بطاقة: برنامج الوالدين والأجداد PGP — **متوقف عن استقبال طلبات جديدة**

المصدر: [Canada takes steps to responsibly manage the PGP](https://www.canada.ca/en/immigration-refugees-citizenship/news/notices/responsibly-manage-parent-grandparent-program.html) (15-7-2026، استرجاع 22-11-2026).

| الحقل | القيمة |
|---|---|
| الاسم الرسمي | Parents and Grandparents Program (PGP) |
| الجهة المالكة | IRCC |
| النوع | إقامة دائمة — كفالة والدين/أجداد |
| الأهلية من خارج كندا | المكفول عادة خارج كندا (ليس شرطاً مطلقاً) |
| الجنسية/العمر/التعليم/الخبرة/اللغة للمكفول | لا متطلبات |
| الكفيل | مواطن/مقيم دائم ≥18 سنة، مقيم في كندا |
| عرض عمل/LMIA | غير منطبق |
| الأموال (تاريخياً) | دخل كفيل ≥ الحد الأدنى + 30% لثلاث سنوات ضريبية؛ تعهد 20 سنة (شروط آخر استقبال؛ قد تتغير عند إعادة الفتح) |
| الرسوم | كفالة + معالجة + حق الإقامة الدائمة (القائمة الرسمية) |
| الطبي/الأمني | فحص طبي + حسن سيرة للمكفول |
| المستندات | نموذج اهتمام → دعوة → حزمة كفالة |
| **التقديم (الوضع 22-11-2026)** | **موقوف:** لا نماذج اهتمام جديدة ولا دعوات حتى إشعار آخر (إشعار 15-7-2026). الطلبات القائمة تُعالج؛ هدف الموافقات 15,000 في 2026 و15,000 سنوياً في خطة 2027–2029 |
| المراحل | اهتمام → دعوة → طلب → قرار (حالياً: معالجة المخزون فقط) |
| أوقات المعالجة | متغيرة — أداة IRCC |
| المرافقون | الزوج/الشريك للمكفول |
| حقوق العمل/الدراسة | كاملة بعد PR |
| التحول إلى PR | هو إقامة دائمة |
| أسباب الرفض | دخل الكفيل، عدم قبول طبي/أمني |
| المخاطر/البديل | إيقاف مفتوح المدة؛ البديل المتاح: **Super Visa** (قسم 3.3) |
| آخر تحديث | إشعار الإيقاف 15-7-2026 |
| المصدر | [إشعار إدارة PGP](https://www.canada.ca/en/immigration-refugees-citizenship/news/notices/responsibly-manage-parent-grandparent-program.html) (استرجاع 22-11-2026) |
