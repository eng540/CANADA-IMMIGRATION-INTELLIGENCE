# بطاقة: العاملون لحسابهم (موقوف)

> **مصدر هذا الملف**: حزمة بحث «الدراسة والأسرة والحماية والأعمال» — النسخة المنقحة الثانية (استرجاع 2026-11-22)، راجعها مالك التكامل وتحقق من بنودها المحسوبة من مصادرها الرسمية قبل دمجها في هذا المستودع. روابط المصادر مضمنة في النص كما وردت. البطاقات بصيغة جداول الحزمة وتُستكمل لاحقاً نحو قالب الـ25 حقلاً الكامل حيث نقصت حقول.

### 7.2 بطاقة: برنامج العاملين لحسابهم الخاص (Self-Employed) — **موقوف حتى إشعار آخر**

| الحقل | القيمة |
|---|---|
| الاسم الرسمي | Self-Employed Persons Program |
| الجهة المالكة | IRCC |
| النوع | إقامة دائمة — أعمال (ثقافة/رياضة) |
| الوضع | **موقوف كلياً عن الاستقبال منذ 30-4-2024، مُدد حتى إشعار آخر في 19-12-2025**؛ المعالجة مستمرة للمخزون (تراكم تجاوز 4 سنوات) |
| الأهلية من خارج كندا | نعم تاريخياً (مغلق حالياً) |
| الجنسية/العمر | مفتوح / لا قيد |
| التعليم | لا حد رسمي |
| الخبرة | خبرة بارزة في الفنون/الثقافة/الترفيه/الرياضة ونية وقدرة على العمل الذاتي في كندا |
| اللغة | لا حد أدنى معلن (تدخل في التقييم النقطي تاريخياً) |
| عرض عمل/LMIA | غير مطلوب |
| الأموال | إثبات القدرة على الاستقرار (تاريخياً) |
| الرسوم | رسوم PR (القائمة الرسمية) |
| الطبي/الأمني | ينطبق |
| المستندات/التقديم/المراحل | حزمة IMM 4500 → تقييم → قرار (للمخزون فقط حالياً) |
| أوقات المعالجة | >4 سنوات عند الإيقاف؛ رقم حي من أداة IRCC |
| المرافقون | الأسرة ضمن الطلب |
| حقوق العمل/الدراسة | بعد PR فقط |
| التحول إلى PR | هو مسار PR |
| أسباب الرفض | عدم إثبات الخبرة البارزة أو القدرة على العمل الذاتي |
| المخاطر | إيقاف مفتوح المدة؛ الطلبات القائمة ضمن فئة العمال في الإجراء المؤقت 2027 |
| آخر تحديث | إشعار 19-12-2025 (تمديد الإيقاف) |
| المصدر | [إشعار تدابير رواد الأعمال](https://www.canada.ca/en/immigration-refugees-citizenship/news/notices/immigration-measures-entrepreneurs.html) و[تغييرات 2024](https://www.canada.ca/en/immigration-refugees-citizenship/news/2024/04/changes-to-the-start-up-visa-and-self-employed-persons-programs-to-help-reduce-backlogs-and-improve-processing-times.html) (استرجاع 22-11-2026) |
