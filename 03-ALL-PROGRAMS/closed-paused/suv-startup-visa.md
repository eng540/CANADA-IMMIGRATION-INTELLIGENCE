# بطاقة: تأشيرة الشركات الناشئة SUV (متوقفة)

- آخر تحقق: 2026-11-22
- الحالة: **متوقفة عن الطلبات الجديدة** (توقف كامل موسوم 2026-06-30 على الصفحة الرسمية)

1. **الاسم الرسمي**: Start-up Visa Program (SUV)
2. **الجهة الحكومية المسؤولة**: IRCC
3. **نوع الإقامة**: دائمة — أعمال/ريادة
4. **هل يقبل المتقدم من خارج كندا؟** تاريخياً نعم؛ حالياً مغلق للطلبات الجديدة
5. **الجنسية والبلدان المؤهلة**: مفتوح
6. **العمر والشروط العمرية**: لا قيد
7. **المؤهل العلمي**: لا حد رسمي؛ تقييم الجهة المعينة للمشروع
8. **الخبرة المهنية**: لا حد رسمي؛ تقييم الجهة المعينة
9. **اللغة المطلوبة**: CLB 5 (تاريخياً)
10. **اشتراط عرض العمل**: غير مطلوب؛ يلزم دعم جهة معينة: صندوق مخاطر 200,000$ أو مجموعة ملائكية 75,000$ أو قبول حاضنة
11. **اشتراط LMIA**: غير مطلوب
12. **إثبات الأموال**: أموال استقرار حسب حجم الأسرة (تاريخياً)
13. **الرسوم الحكومية**: رسوم معالجة PR الاقتصادية 1,525$ + حق الإقامة الدائمة 575$ (قائمة رسوم IRCC 2026-11-22)
14. **الفحوص الطبية والأمنية**: ينطبق
15. **المستندات المطلوبة**: خطاب دعم الجهة، إثبات لغة وأموال، وثائق هوية
16. **طريقة التقديم**: **مغلق للجديد** — متوقف عن استقبال طلبات PR جديدة منذ 2025-12-31 (استثناء: التزامات سارية من جهات معينة صدرت 2025 ولم يُقدَّم عليها)، ثم توقف كامل موسوم «2026-06-30». المعالجة مستمرة للمخزون بأولوية لمن داخل كندا بتصريح عمل SUV
17. **مراحل المعالجة**: دعم جهة ← طلب PR ← (سابقاً تصريح عمل اختياري) ← قرار
18. **مدة المعالجة الرسمية المنشورة**: لم تُسترجع (الصفحة تعذر تحميل بياناتها)؛ تراكم تاريخي طويل
19. **إمكانية اصطحاب الزوجة والأطفال**: الزوج/الشريك والمعالون ضمن الطلب
20. **حقوق العمل والدراسة**: تصريح العمل الاختياري: توقف الجديد منذ 2025-12-19 (تمديدات داخل كندا فقط)؛ تصريح مفتوح محتمل لأصحاب الطلبات القائمة وفق الصفحة الرسمية
21. **إمكانية الانتقال إلى الإقامة الدائمة**: هو مسار PR (للمقبولين)
22. **الموانع وأسباب الرفض**: عدم جدية المشروع؛ سقف الـ10 شركات لكل جهة منذ 2024-04-30
23. **المخاطر والتكاليف غير الحكومية**: برنامج موقوف؛ أصحاب الطلبات القائمة مشمولون ضمن فئة العمال في الإجراء المؤقت 2027
24. **آخر تحديث للبرنامج**: سقف الجهات وأولوية رأس المال الكندي/حاضنات Canada's Tech Network (2024-04-30)؛ إيقافات 2025-12-19 و2026-06-30؛ هدف القبولات ضمن «الأعمال الفيدرالية»: 1,500 (2027)؛ **برنامج تجريبي جديد مستهدف لرواد الأعمال سيُعلن في 2026 — التفاصيل مجهولة صراحة حتى الاسترجاع**
25. **رابط المصدر الحكومي المباشر**: [SUV: About](https://www.canada.ca/en/immigration-refugees-citizenship/services/immigrate-canada/start-visa/about.html) (موسومة Paused) · [إشعار تدابير رواد الأعمال 2025-12-19](https://www.canada.ca/en/immigration-refugees-citizenship/news/notices/immigration-measures-entrepreneurs.html) · [تغييرات أبريل 2024](https://www.canada.ca/en/immigration-refugees-citizenship/news/2024/04/changes-to-the-start-up-visa-and-self-employed-persons-programs-to-help-reduce-backlogs-and-improve-processing-times.html) (استرجاع 2026-11-22)
