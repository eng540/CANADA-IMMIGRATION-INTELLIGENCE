### 3.4 بطاقة برنامج: الخبرة الدولية IEC (عطلة عمل)

المصادر: [IEC: Who can apply](https://www.canada.ca/en/immigration-refugees-citizenship/services/work-canada/iec/eligibility.html)، [الأهلية حسب الدولة](https://www.canada.ca/en/immigration-refugees-citizenship/services/work-canada/iec/eligibility/eligibility-by-country.html)، [المنظمات المعتمدة RO](https://www.canada.ca/en/immigration-refugees-citizenship/services/work-canada/iec/recognized-organizations.html)، والقائمة الرسمية الكاملة للدول الشريكة في [منشور حكومة كندا Ci4-197-1-2025 (publications.gc.ca)](https://publications.gc.ca/collections/collection_2025/ircc/Ci4-197-1-2025.pdf) (استرجاع 22-11-2026).

| الحقل | القيمة |
|---|---|
| الاسم الرسمي | International Experience Canada (IEC) |
| الجهة المالكة | IRCC |
| النوع | تصاريح عمل شبابية: Working Holiday (مفتوح)، Young Professionals (مرتبط بصاحب عمل)، International Co-op (تدريب) |
| **الجنسية** | مواطنو **36 دولة/إقليماً شريكاً** فقط — القائمة الرسمية الكاملة (منشور حكومة كندا Ci4-197-1-2025 على publications.gc.ca، ومطابق للجزء المسترجع من الصفحة الحية): أندورا، أستراليا، النمسا، بلجيكا، تشيلي، كوستاريكا، كرواتيا، التشيك، الدنمارك، إستونيا، فنلندا، فرنسا، ألمانيا، اليونان، هونغ كونغ، آيسلندا، أيرلندا، إيطاليا، اليابان، لاتفيا، ليتوانيا، لوكسمبورغ، هولندا، نيوزيلندا، النرويج، بولندا، البرتغال، سان مارينو، سلوفاكيا، سلوفينيا، كوريا الجنوبية، إسبانيا، السويد، سويسرا، تايوان، المملكة المتحدة. **القائمة لا تشمل أي دولة عربية أو خليجية، واليمن ليس دولة شريكة** (تحقق من قائمة رسمية كاملة). الأهلية بجنسية جواز التقديم: حامل جنسية ثانية لدولة شريكة مؤهل. **استثناءات ضيقة عبر المنظمات المعتمدة RO:** مواطنو الولايات المتحدة عبر SWAP Working Holidays، ومواطنو الدول الأعضاء في IAESTE عبر IAESTE — لا يذكر أي RO مدرج رسمياً اليمن أو أي دولة عربية صراحة؛ حامل جنسية غير شريكة يتحقق من الصفحة الحية ومن أهلية كل RO على حدة قبل الاستبعاد |
| العمر | غالباً 18–35 (تختلف حسب الدولة: بعضها 18–30) |
| التعليم/الخبرة | Young Professionals: عرض عمل TEER 0-3 (أو TEER 4 بمجال الدراسة مع إثبات مؤهل). Co-op: طالب مسجل بتدريب إلزامي |
| اللغة | لا شرط رسمي |
| عرض عمل | مطلوب فقط لـYoung Professionals وCo-op |
| LMIA | غير مطلوب (ضمن IMP) |
| الأموال | **$2,500** كحد أدنى عند الوصول + تأمين صحي يشمل الإعادة للوطن |
| الرسوم | رسوم IEC + تصريح عمل (تحقق من القائمة الرسمية) |
| قيود أخرى | حاملو وثائق سفر اللاجئين غير مؤهلون؛ بعض الدول تسمح بمشاركة واحدة أو اثنتين |
| التقديم | ملف تعريف في مجموعات المرشحين → دعوة ITA → طلب خلال المهلة |
| التحول إلى PR | لا تحويل مباشر؛ الخبرة الكندية قد تدعم Express Entry لاحقاً |
| آخر تحديث/المصدر | موسم 2026 مفتوح؛ الروابط أعلاه |
