### 5.3 بطاقات إعادة التوطين (من خارج كندا)

المصدر: [How the system works](https://www.canada.ca/en/immigration-refugees-citizenship/services/refugees/about-refugee-system/how-system-works.html) و[Resettle in Canada as a refugee](https://www.canada.ca/en/immigration-refugees-citizenship/services/refugees/resettle-refugee.html) (استرجاع 22-11-2026). أهداف 2027: حكومي GAR 11,750 — خاص PSR 17,550.

| المسار | الآلية | من يحدد الحالة | الدعم |
|---|---|---|---|
| **GAR — اللاجئون بمساعدة حكومية** | إحالة من **UNHCR أو منظمة إحالة معينة أخرى** (مثال رسمي: تيار مدافعي حقوق الإنسان تحيله UNHCR بمساعدة Front Line Defenders وProtectDefenders.eu) → فحص أمني/طبي/جنائي → إقامة دائمة عند الوصول | لا تقديم فردي مباشر؛ للنظر في حالتك سجّل وضع اللجوء لدى UNHCR أو سلطات الدولة | برنامج مساعدة إعادة التوطين RAP: دعم دخل حتى سنة + خدمات استقرار 4-6 أسابيع |
| **PSR — الكفالة الخاصة** | أنواع الكفلاء على الصفحة الرسمية وقت الاسترجاع: أصحاب اتفاقيات الكفالة SAH (**مفتوح**)، مجموعات الخمسة G5 (**موقوف**)، الكفلاء المجتمعيون (**موقوف**)؛ اللاجئ يُحدَّد بإحالة من UNHCR أو منظمة إحالة معينة، أو يحدده الكفيل مباشرة (حالات معروفة للكفيل) | التحديد من UNHCR/منظمة إحالة أو الكفيل؛ فحص IRCC الأمني/الطبي/الجنائي إلزامي | الكفيل يدعم مالياً واجتماعياً سنة (حتى 3 سنوات لحالات خاصة)؛ لا رسوم معالجة ويُمنع على الكفيل طلب مال من اللاجئ |
| **BVOR — المختلط المحال من مكتب التأشيرات** | مطابقة كفلاء خاصين (مواطنين/مقيمين دائمين) مع لاجئين **حددتهم منظمة إحالة مثل UNHCR** | منظمة الإحالة | 6 أشهر دعم مالي حكومي + 6 أشهر دعم مالي من الكفيل + 12 شهر دعم اجتماعي واستقرار من الكفيل |

- **متطلب الإحالة/التحديد:** لا يوجد باب تقديم ذاتي لإعادة التوطين من الخارج؛ من يريد الحماية وهو خارج كندا يسجل لدى UNHCR أو سلطات الدولة في بلد اللجوء الأول، أو يحدده كفيل خاص مؤهل ضمن PSR.
#### بطاقة 25 حقلاً: GAR (إعادة توطين بمساعدة حكومية)

| الحقل | القيمة |
|---|---|
| الاسم الرسمي | Government-Assisted Refugees (GAR) Program |
| الجهة المالكة | IRCC |
| النوع | إعادة توطين — إقامة دائمة عند الوصول |
| الأهلية من خارج كندا | حصرياً (لمن هم خارج كندا وخارج بلدهم) |
| الجنسية | مفتوح؛ يشمل تيارات لمدافعي حقوق الإنسان ولأفراد LGBTQI+ |
| العمر/التعليم/الخبرة/اللغة | لا متطلبات |
| عرض عمل/LMIA | غير منطبق |
| الأموال | لا يُشترط مال؛ دعم حكومي RAP حتى سنة |
| الرسوم | لا رسوم معالجة |
| الطبي/الأمني | فحص طبي + تدقيق أمني وجنائي إلزامي |
| المستندات | حسب ملف الإحالة؛ لا حزمة تقديم ذاتي |
| التقديم | **غير متاح ذاتياً** — إحالة من UNHCR أو منظمة إحالة معينة أخرى؛ التسجيل لدى UNHCR أو سلطات الدولة شرط النظر |
| المراحل | تسجيل → إحالة → فحص كندي → قرار → سفر |
| أوقات المعالجة | متغيرة حسب مكتب التأشيرات — أداة IRCC الرسمية |
| المرافقون | أفراد الأسرة ضمن ملف الإحالة |
| حقوق العمل/الدراسة | كاملة كمقيم دائم عند الوصول |
| التحول إلى PR | إقامة دائمة مباشرة |
| أسباب الرفض | عدم استيفاء تعريف اللاجئ، عدم قبول أمني/طبي/جنائي |
| المخاطر | الاعتماد كلياً على الإحالة؛ لا يمكن شراء أو طلب الإحالة |
| آخر تحديث | هدف 2027: 11,750 |
| المصدر | [GAR program](https://www.canada.ca/en/immigration-refugees-citizenship/services/refugees/resettle-refugee/government-assisted-refugee-program.html) (استرجاع 22-11-2026) |

#### بطاقة 25 حقلاً: PSR (الكفالة الخاصة للاجئين)

| الحقل | القيمة |
|---|---|
| الاسم الرسمي | Private Sponsorship of Refugees (PSR) Program |
| الجهة المالكة | IRCC (لكيبيك مسار خاص عبر حكومة كيبيك) |
| النوع | إعادة توطين بكفالة خاصة — إقامة دائمة عند الوصول |
| الأهلية من خارج كندا | حصرياً |
| الجنسية | مفتوح |
| العمر/التعليم/الخبرة/اللغة | لا متطلبات |
| عرض عمل/LMIA | غير منطبق |
| الأموال | على الكفيل (خطة مالية); **لا يُسمح للكفيل بطلب مال من اللاجئ** |
| الرسوم | لا رسوم معالجة |
| الطبي/الأمني | فحص طبي + تدقيق أمني/جنائي إلزامي |
| المستندات | يقدمها الكفيل مع ملف اللاجئ |
| التقديم | **حسب فئة الكفيل (وضع 22-11-2026):** SAH **مفتوح**؛ مجموعات الخمسة G5 **موقوف**؛ الكفلاء المجتمعيون **موقوف** — إجمالي هدف PSR (17,550 لعام 2027) لا يعني استقبالاً مفتوحاً لكل الفئات |
| المراحل | تحديد اللاجئ (إحالة UNHCR/منظمة معينة أو تحديد الكفيل) → طلب الكفيل → فحص → قرار → سفر |
| أوقات المعالجة | طويلة ومتغيرة — أداة IRCC؛ **مجهول رقمي صريح** |
| المرافقون | أفراد الأسرة ضمن الملف |
| حقوق العمل/الدراسة | كاملة كمقيم دائم |
| التحول إلى PR | إقامة دائمة مباشرة |
| أسباب الرفض | عدم استيفاء التعريف، عدم أهلية الكفيل/خطته، عدم قبول أمني/طبي |
| المخاطر | إيقاف فئات الكفالة؛ زخم الطلبات |
| آخر تحديث | إيقاف G5 والكفلاء المجتمعيين ظاهر على الصفحة الرسمية وقت الاسترجاع |
| المصدر | [How to sponsor a refugee](https://www.canada.ca/en/immigration-refugees-citizenship/services/refugees/sponsor-refugee/private-sponsorship-program.html) و[معلومات للاجئين](https://www.canada.ca/en/immigration-refugees-citizenship/services/refugees/sponsor-refugee/private-sponsorship-program/refugees-information.html) (استرجاع 22-11-2026) |

#### بطاقة 25 حقلاً: BVOR (المختلط المحال)

| الحقل | القيمة |
|---|---|
| الاسم الرسمي | Blended Visa Office-Referred (BVOR) Program |
| الجهة المالكة | IRCC |
| النوع | إعادة توطين مختلط (حكومي + خاص) — إقامة دائمة عند الوصول |
| الأهلية من خارج كندا | حصرياً |
| الجنسية/العمر/التعليم/الخبرة/اللغة | مفتوح / لا متطلبات |
| عرض عمل/LMIA | غير منطبق |
| الأموال | مقاسمة: 6 أشهر دعم مالي حكومي + 6 أشهر من الكفيل + 12 شهر دعم اجتماعي من الكفيل |
| الرسوم | لا رسوم معالجة |
| الطبي/الأمني | فحص إلزامي |
| المستندات | عبر المطابقة؛ لا تقديم ذاتي |
| التقديم | غير متاح ذاتياً — مطابقة الكفيل مع لاجئ حددته **منظمة إحالة مثل UNHCR** |
| المراحل | إحالة → إدراج للمطابقة → التزام كفيل → فحص → سفر |
| أوقات المعالجة | متغيرة — أداة IRCC |
| المرافقون | ضمن ملف الإحالة |
| حقوق العمل/الدراسة | كاملة كمقيم دائم |
| التحول إلى PR | إقامة دائمة مباشرة |
| أسباب الرفض | كسابقيه |
| المخاطر | عدم توفر مطابقة |
| آخر تحديث | ضمن أهداف إعادة التوطين 2027 |
| المصدر | [BVOR: About](https://www.canada.ca/en/immigration-refugees-citizenship/services/refugees/sponsor-refugee/private-sponsorship-program/blended-visa-office-program.html) (استرجاع 22-11-2026) |

- تتضمن مسارات GAR تيارات لمدافعي حقوق الإنسان ولأفراد LGBTQI+.
- **مجهول صراحة:** أوقات معالجة PSR طويلة ومتغيرة حسب مكتب التأشيرات (لم تُسترجع أرقام محدثة).
