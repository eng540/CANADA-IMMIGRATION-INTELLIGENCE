### 5.4 بطاقة: الاعتبارات الإنسانية والرأفة H&C

المصدر: [Humanitarian and compassionate grounds](https://www.canada.ca/en/immigration-refugees-citizenship/services/refugees/protection/refusal-options/humanitarian-compassionate-grounds.html) (استرجاع 22-11-2026).

| الحقل | القيمة |
|---|---|
| الاسم الرسمي | Humanitarian and Compassionate (H&C) considerations — طلب إقامة دائمة استثنائي |
| الجهة | IRCC |
| النوع | إقامة دائمة استثنائية (تقديرية، حالة بحالة) |
| الأهلية من خارج كندا | نعم — ضمن طلب تأشيرة PR من الخارج أيضاً |
| الجنسية/العمر/التعليم/الخبرة/اللغة | لا متطلبات برنامجية (الاستثناء هو جوهر المسار) |
| عرض عمل/LMIA | غير مطلوب |
| الأموال | لا حد رسمي؛ الاستقرار المالي عامل مؤثر |
| الرسوم | رسوم معالجة PR (القائمة الرسمية) |
| الطبي/الأمني | القبول الطبي/الأمني ينطبق |
| المستندات | حزمة H&C (دليل 5291 + IMM 5280/5283) وأدلة الاستقرار والروابط ومصلحة الأطفال |
| لمن | حالات استثنائية لمن لا يستوفي شروط أي برنامج؛ **فقط** ضمن طلب إقامة دائمة (داخل كندا أو تأشيرة PR من الخارج) — لا يقبل من المقيمين المؤقتين |
| العوامل | الاستقرار في كندا، الروابط الأسرية، مصلحة الأطفال الفضلى، عواقب الرفض |
| قيود صارمة | طلب واحد فقط بالوقت الواحد؛ **لا تُقيَّم مخاطر الاضطهاد/التعذيب** (هذه للجوء)؛ ممنوع مع ادعاء لجوء قائم (يجب السحب قبل جلسة IRB)؛ **منع سنة واحدة** بعد قرار IRB سلبي (استثناء: أطفال متضررون أو حالة طبية مهددة للحياة)؛ "الأجانب المخصصون" (وصول غير نظامي جماعي) ينتظرون 5 سنوات |
| أمر الإبعاد | تقديم H&C **لا يوقف الإبعاد**؛ يجب المغادرة في موعدها وتُستكمل المعالجة من الخارج |
| الضمانات | **لا ضمان للقبول ولا حق استئناف**؛ مراجعة قضائية محتملة أمام المحكمة الفيدرالية |
| هدف 2027 | 5,000 (ضمن فئة H&C وأخرى) + إنهاء طلبات الموافق عليهم مبدئياً ضمن الإجراء المؤقت |
| التقديم | طلب PR ورقي/إلكتروني بأسباب H&C |
| المراحل | تقديم → تقييم تقديري → موافقة مبدئية محتملة → قرار نهائي |
| أوقات المعالجة | متغيرة/طويلة — أداة IRCC؛ **مجهول رقمي صريح** |
| المرافقون | أفراد الأسرة ضمن الطلب |
| حقوق العمل/الدراسة | الموافقة المبدئية قد تؤهل لتصريح عمل مفتوح ضمن الفئات المذكورة رسمياً |
| التحول إلى PR | هو طلب PR |
| أسباب الرفض | عدم كفاية الاعتبارات الاستثنائية، القيود القانونية أعلاه |
| المخاطر | تقديري بالكامل؛ لا يوقف الإبعاد |
| آخر تحديث | ضمن الإجراء المؤقت 2027 (إنهاء طلبات الموافق عليهم مبدئياً) |
| المصدر | الرابط أعلاه |
