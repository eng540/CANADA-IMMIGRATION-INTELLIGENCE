# 02 — بنية المنظومة (IMMIGRATION SYSTEM)

آخر تحديث: 2026-11-22

هذا القسم يشرح بنية المنظومة كاملة. الحالة التفصيلية لكل برنامج (بطاقات 25 حقلاً) تُبنى في `03-ALL-PROGRAMS` خلال المرحلتين الثانية والثالثة.

## الأقسام السبعة

1. **الإقامة الدائمة الاقتصادية الفيدرالية**: Express Entry (FSW/CEC/FST + فئات قطاعية)، وأبوابها موصوفة في [01-START-HERE](../01-START-HERE/how-the-system-works.md).
2. **الإقامة الدائمة عبر المقاطعات والمجتمعات**: PNP (11 مقاطعة/إقليماً)، AIP، RCIP (دائم من 2026-11)، FCIP (تجريبي)، كيبيك (اختيار مستقل).
3. **العمل المؤقت**: TFWP (بـLMIA) وIMP (معفى)؛ تصاريح مرتبطة بصاحب عمل أو مفتوحة بفئات محددة.
4. **الدراسة**: تصريح دراسة عبر DLI، العمل أثناء الدراسة وبعدها (PGWP بشروط)، التكاليف والمخاطر.
5. **الأسرة**: كفالة الزوج/الشريك/الأبناء (مفتوحة)، الوالدون والأجداد (متوقفة حالياً — تحقق 2026-11-22)، Super Visa للزيارات الطويلة.
6. **الإنساني والحماية**: إعادة توطين من الخارج بلا تقديم ذاتي: GAR بإحالة UNHCR أو منظمة إحالة معينة، أو كفالة خاصة PSR (SAH مفتوحة؛ Community Sponsors وGroups of Five متوقفتان حالياً — تحقق 2026-11-22) وقد يحدد الكفيل اللاجئ مباشرة، أو BVOR المختلط؛ اللجوء من الداخل/الحدود مسار منفصل بقواعد 2026 المشددة؛ H&C الاستثنائية.
7. **الأعمال**: Start-up Visa (متوقف)، Self-Employed (متوقف)، Agri-Food Pilot (مغلق للجديد)، مسارات رواد الأعمال الإقليمية (تفصيلها في المرحلة الثانية).

## خريطة الحالة السريعة (تحقق 2026-11-22)

| المسار | الحالة |
|---|---|
| Express Entry | يعمل؛ جولات موقوفة مؤقتاً حتى ~أسبوعين من 2026-11-03 لإعادة حساب CRS |
| فئات EE 2026 | عشر فئات حالية (تحقق 2026-11-22): فرنسية، صحة وخدمات اجتماعية، STEM (تشمل المهندسين المدنيين NOC 21300)، حِرَف، تعليم، نقل، وأطباء وباحثون ومدراء كبار بخبرة كندية، ومجندون عسكريون |
| PNP | يعمل؛ حصص 91,500 (2026) و92,500 (2027–2028) |
| AIP | يعمل؛ عرض عمل من صاحب عمل معتمد إلزامي |
| RCIP | تحول لبرنامج دائم (إعلان 2026-11-09)؛ 14 مجتمعاً |
| FCIP | تجريبي قائم؛ 6 مجتمعات |
| كيبيك (عمال مهرة) | قائم باختيار مسبق CSQ |
| Home Care Worker Immigration pilots | مغلقة |
| Start-up Visa | متوقف (انقضت مهلته 2026-06-30) |
| Self-Employed Persons | متوقف |
| Agri-Food Pilot | مغلق للطلبات الجديدة |
| كفالة الوالدين والأجداد PGP | متوقفة |
| كفالة الزوج/الأبناء | مفتوحة |
| Community Sponsors / Groups of Five (لاجئون) | متوقفتان |

## ملفات هذا الدليل

- `ee-high-wage-occupations.md` — قائمة المهن عالية الأجر لنقاط CRS (سارية من 2026-11-03، S27) بجداولها الكاملة.

## ما يُنتظر توثيقه (فجوات معلنة)

- حالة كل مسار PNP على حدة (11 جهة × عدة مسارات) — المرحلة الثانية.
- وضع كيبيك التفصيلي (PSTQ/PEQ بعد تعديلات 2025) — المرحلة الثانية.
- أهلية اليمن لبرامج مثل International Experience Canada — المرحلة الثانية (المؤشرات الأولية: ليست ضمن الدول المشاركة، يُؤكد بالمصدر).
- قوائم المهن ذات الأولوية لكل مجتمع ريفي/فرنكوفوني — المرحلة الرابعة/الخامسة.
- أثر الإجراءات المؤقتة المرتبطة بتنبيه الصحة العامة (Ebola، ممددة حتى 2026-11-27) على المتقدمين من دول محددة — يُوثق عند ورود تفاصيلها.
